M Backup

M Backup is a database backup utility designed to create, verify, and securely store backup files.

Google Drive Integration

M Backup can optionally connect to a user's Google Drive to upload backup files created by the application.

Google Drive access is used only for backup storage and management of files created or used by M Backup.

Data Handling

M Backup does not sell user data or use Google user data for advertising, profiling, or unrelated purposes.

Google authorization credentials used by the desktop application are stored locally using operating-system protected storage.
