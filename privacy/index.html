M Backup Privacy Policy

Last updated: October 4, 2026

M Backup is a desktop database backup utility that can optionally connect to a user's Google Drive for backup storage.

Google User Data Access

M Backup uses Google OAuth authorization only when the user explicitly chooses to connect Google Drive.

M Backup requests the Google Drive drive.file permission. This permission is intended to limit access to files created by, opened with, or otherwise explicitly made available to M Backup.

M Backup does not request unrestricted access to all files in the user's Google Drive.

How Google User Data Is Used

Google Drive access is used only to provide backup-related functionality, including uploading, verifying, and managing backup files associated with M Backup.

Google user data is not used for advertising, profiling, marketing, or purposes unrelated to backup functionality.

Backup Data

When Google Drive backup is enabled, M Backup may upload backup archives and associated metadata files to the user's Google Drive.

The current cloud backup workflow uploads backup ZIP files and their associated JSON metadata. Database credentials and raw temporary SQL dump files are not uploaded as part of the Google Drive backup workflow.

OAuth Credential Storage

OAuth authorization tokens used by the desktop application are stored locally on the user's Windows computer using operating-system protected storage.

These credentials are not intentionally published or included in backup files uploaded to Google Drive.

Data Sharing

M Backup does not sell Google user data.

M Backup does not share Google user data with third parties for advertising, analytics, profiling, or marketing purposes.

Data is transmitted to Google only as necessary to provide the Google Drive backup functionality requested by the user.

Data Retention and User Control

OAuth authorization remains available locally until it is cleared, revoked, or otherwise becomes invalid.

Users may revoke M Backup's Google access through their Google Account permissions. Revoking access prevents future Google Drive API access by M Backup.

Files already stored in Google Drive remain under the user's Google Drive account and can be managed or deleted by the user.

Google API Services User Data Policy

M Backup's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy , including the Limited Use requirements.

Changes to This Privacy Policy

This Privacy Policy may be updated if M Backup changes how it accesses, uses, stores, or shares Google user data. The latest version will be published on this page.
